# 쿠팡 파트너스 — 이 프로젝트에 적용한 준수 사항

> 약관·운영정책 원문 발췌와 계정 사고 이력은 **`goldbox-today/docs/coupang-partners-policy-notes.md`** 가 단일 출처다.
> 이 문서는 그 정책을 몇점이야?(score.drawyourmind.com)에 어떻게 반영했는지만 적는다.
> 작성 2026-09-25 — 선물 추천(`/gift`) 기능 도입 시점.

## 계정 상황 (왜 보수적으로 가는가)

같은 파트너스 계정을 골드박스투데이·랭킹박스·프라이스갭이 공유한다. 그리고 이 계정은 이미:

- **계정 해지 1회** — 아내 명의 계정(AF0586521), 사유 "채널명 내 쿠팡 상호명 포함" (운영정책 4.1 6) 3항, C등급 즉시 해지)
- **API 이용 제한 1회** — 2026-09-19, 검색 API 시간당 초과 경고 3회 누적

연관 계정 조항(운영정책 4.2 1))이 있어, 한 채널의 위반이 계정 전체로 번진다. 경고가 싼 계정이 아니다.

## 채널 등록

| 항목 | 값 | 근거 |
|---|---|---|
| 채널 URL | `https://score.drawyourmind.com` | 채널은 사이트 단위 — 루트로 등록해야 전체가 커버된다 |
| 채널 ID | **`scoregift`** | 영문. 딥링크에 subId 로 박혀 골드박스와 성과·정산을 가른다 (`COUPANG_SUB_ID`) |
| 채널 표시명 | 쿠팡 상호 금지 | "쿠팡"을 넣으면 안 된다 — 정확히 이 사유로 계정이 해지된 적 있다 |

> 장부 스코프(`LEDGER_SITE = "score"`)는 채널 ID와 다른 값이다. 전자는 우리 Supabase 쿼터
> 장부에서 프로젝트를 가르는 이름(도메인 기준), 후자는 쿠팡 쪽 채널 식별자다.

## 코드에 박아둔 방어

### 1. 상호 사용 — `src/lib/family.ts`
크로스링크 카피에서 "쿠팡 골드박스" → "골드박스" 로 정리했다. 서비스명이 "골드박스투데이"라 의미 전달에 지장이 없고, 운영정책 4.1 6) 은 상호 자체의 사용을 제재 대상으로 삼는다. 파일 상단에 경고 주석을 남겼다 — **이 문구들에 "쿠팡"을 다시 넣지 말 것.**

### 2. 금지 브랜드 — 구조적으로 안전
`goldbox-today/lib/blocked-brands.ts` 의 54개를 선물 카탈로그 74종 전부와 대조 → **충돌 0건.**

골드박스는 상품명이 그대로 `<title>`·h1 에 박혀 위반 게시물이 자동 생성되는 구조지만, 여기는 사람이 고정한 일반 카테고리명(`무드등`, `향초 선물세트`)만 쓴다. **브랜드명이 유입될 경로 자체가 없다.** 금지 리스트가 갱신돼도 이 프로젝트는 점검 대상이 아니다.

> 단, 카탈로그에 브랜드명을 넣는 순간 이 면제는 깨진다. `src/data/gifts.json` 의 `label`·`query` 는 일반 명사만 쓴다.

### 3. 오인 가능성 — 예산 표기
가격대 라벨을 `1~2만원대` → `예산 1~2만원` 으로 바꾸고, 고지 문구에 "표시된 금액은 선물 예산 가이드고, 실제 판매가는 링크에서 확인해"를 넣었다. 링크가 검색 결과라 가격이 제각각인데 상품명 옆에 금액만 붙으면 그 상품 가격으로 읽힌다 (약관 제8조 2항 — 사실과 다르거나 오인 가능성 있는 내용 게시).

### 4. API 데이터 미저장
오픈 API 약관 제5조 3항은 API 데이터의 복제·저장·전송을 금한다. 이 프로젝트가 저장하는 것은 **딥링크 URL뿐**이다 — 상품명·가격·이미지·재고를 일절 받지 않는다. 골드박스가 안고 있는 가격 이력 축적 리스크가 여기엔 없다.

> **실시간 가격이나 상품 정보를 붙이자는 제안이 나오면 이 항목을 먼저 읽을 것.** 붙이는 순간 리스크 성격이 완전히 바뀐다.

### 5. API 호출량 — 계정 공용 장부 경유
한도는 액세스키(계정) 단위다. `scripts/gen-coupang-links.mjs` 는 매 호출 전에 `cp_try_consume_quota('score', 'coupang-deeplink')` 를 거치고, **fail-closed** 다 — 장부에 못 닿거나 한도를 넘으면 한 콜도 안 쏘고 중단한다.

- 정책 행: `supabase/migrations/20260925-cp-api-policy-score.sql` (5/분 · 12/시 · 24/일)
- 실제 필요량은 **최초 1회 4콜** (74종 ÷ 20). 한도를 필요량 바로 위로 잡아, 반복 실행 시 계정 한도에 닿기 전에 여기서 먼저 막힌다.
- 런타임에는 API를 전혀 쓰지 않는다. 딥링크는 빌드 전에 JSON 으로 커밋된다.

### 6. 링크 표기
- 수수료 고지: 제휴 링크가 나오기 **전에** 한 번 (`AffiliateNotice`) — `/gift`, `/gift/[type]` 양쪽
- `rel="sponsored nofollow noopener noreferrer"`
- 쿠팡 로고·BI 미사용. 버튼 문구는 "보러가기"

### 7. 미등록 미디어 노출 방지
약관 제8조 2항은 파트너스에 **등록되지 않은 미디어**에 광고를 노출하는 것을 금한다. `gift-links.json` 이 비어 있으면 버튼과 결과 화면 CTA가 자동으로 숨는다(`GIFT_LINKS_READY`). 승인 전에 배포해도 제휴 링크가 노출되지 않는다.

심사용 스크린샷이 필요하면 `NEXT_PUBLIC_GIFT_PREVIEW=1` 로 **비제휴 일반 검색 링크**를 노출한다 — 수수료가 붙지 않으므로 미등록 상태에서도 문제없다.

## 배포 순서

```
1. supabase/migrations/20260925-cp-api-policy-score.sql 적용   ← 안 하면 스크립트가 거부됨
2. NEXT_PUBLIC_GIFT_PREVIEW=1 로 배포 → 심사용 스크린샷
3. 채널 등록 (URL=루트, 채널 ID=`scoregift`)
4. 승인 후 npm run gift-links
5. NEXT_PUBLIC_GIFT_PREVIEW 제거하고 재배포
```
